# Glossary

- **Direction / `/direction`** [03:07] [seen]: Command that compares the built app to the plan folder and returns on/off-course, a scorecard, and a drift list.
- **Drift** [03:07] [seen]: Built behavior that does not appear in the PRD/requirements. Either document it or delete it [03:39] [seen].
- **Error-free session** [10:26] [seen]: A customer journey that completes with nothing going wrong. Favorite metric in the interview.
- **First-time-user agent** [11:19] [seen]: Agent that uses the product in a browser as a new customer. Must not read or edit source; hooks enforce that [11:49] [seen].
- **Breaker agent** [09:13] [seen]: Adversarial agent that tries to break the app under concurrency, misuse, and load, on copied data [09:55] [seen].
- **Must-not-trade-off** [07:56] [seen]: Section of project agent instructions listing invariants. Each entry needs a test [07:56] [seen].
- **MVP (here)** [01:50] [seen]: First working version of the basic PRD features, used to judge whether the idea is worth a full build.
- **Quality gate** [06:30] [seen]: Check that something is **good enough**, not merely that a test passed. Often a review agent [06:58] [seen].
- **Scorecard** [03:39] [seen]: `/direction` output summarizing alignment. Exact dimensions not specified [03:39] [unknown].
- **Security debt** [05:09] [seen]: Accumulated security problems from agent-scale code that humans cannot fully review, while attackers also use agents [05:10] [seen].
- **Slop debt** [06:30] [seen]: Messy code you deliberately accept to move fast. Budget it; do not put it on trusted customer paths.
- **DeepSec** [05:34] [seen]: Vercel security-scan tool for agent-written code. Setup writes `.deepsec/` and a short app/auth brief [05:52] [seen].
- **Specs / PRD folder** [01:19] [seen]: First project document set; heading for `/direction`.
- **Token vanity** [02:09] [seen]: Treating tokens spent or changes shipped as proof of progress.
- **Feedback MCP loop** [13:02] [seen]: MCP connections (Gmail, Sentry, …) that ingest reports, auto-fix clear bugs, and escalate ambiguous feedback [13:32] [seen].
- **`CLAUDE.md` / `AGENTS.md`** [07:56] [guessed]: Project instruction files for the must-not-trade-off section. Captions said `claw.md` [07:56] [seen].
